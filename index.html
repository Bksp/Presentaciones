🚀 Cómo Crear una Nueva Presentación

1

Copiar Plantilla

Elige tu formato preferido (HTML o Markdown) y duplícalo en presentaciones/:

cp -r plantillas/markdown presentaciones/mi-charla
2

Editar Contenido

Edita diapositivas.md o index.html según la plantilla que elegiste.

3

Iniciar Servidor

Ejecuta el comando en tu terminal para ver los cambios en tiempo real con servidor local:

npm start
