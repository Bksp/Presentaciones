Introducción

¿Qué es CuidApp?

Una aplicación médica diseñada para centralizar la información del paciente, facilitar el acceso a expedientes y monitorear la salud en tiempo real.

Arquitectura

Plana (Java / XML, sin MVC/MVVM)

Componentes

4 Activities + 1 Service

Entorno de Desarrollo

Stack Tecnológico

Lenguaje

Java - Android

Interfaz

XML · Material Components · Tema Oscuro Material 3

SDK (Min / Target / Compile)

API 31 (Android 12) / API 36 (Android 16) / API 36

Paquete

com.santo_tomas.cuidapp

Interfaz & Navegación

Menú Principal (MenuPrincipalActivity)

Hub Central de la App

Punto de entrada con navegación directa hacia los tres módulos clínicos clave y dos acciones rápidas integradas con el sistema.

Navegación Interna (Intents Explícitos)

  • Ficha del Paciente: perfil clínico y contactos de emergencia.
  • Expedientes Médicos: carga y visualización de documentos.
  • Monitoreo Diario: métricas y sensor cardíaco en tiempo real.

Accesos Rápidos del Sistema (Intents Implícitos)

  • Buscar Hospital Cercano: abre mapas con query (geo:0,0?q=hospital).
  • Portal MINSAL: abre el navegador web oficial del Ministerio de Salud.
Perfil & Emergencias

Ficha del Paciente (FichaPacienteActivity)

Datos Clínicos Críticos

Visualización clara de Nombre, RUT, Grupo Sanguíneo y Alergias para atención médica oportuna.

Edición Dinámica

Diálogo modal interactivo para modificar y actualizar los datos del paciente sin abandonar la pantalla.

Integración con Servicios del SO

  • Llamar Emergencia: marcación directa al 131 (ACTION_DIAL).
  • Correo a Cuidador: cliente de correo (ACTION_SENDTO).
  • Foto de Perfil: captura con la app de cámara (ACTION_IMAGE_CAPTURE).
Gestión Documental

Expedientes Médicos (MisExpedientesActivity)

Almacenamiento y Acceso a Documentos

Módulo dedicado a la gestión y consulta de exámenes, recetas y documentos clínicos digitales del paciente.

Selector de Archivos (SAF)

Utiliza ACTION_GET_CONTENT con tipo MIME application/pdf para invocar el explorador de documentos del sistema de forma segura.

Navegación Consistente

Botón Volver al Menú que limpia la pila de actividades mediante FLAG_ACTIVITY_CLEAR_TOP y SINGLE_TOP.

Telemetría y Salud

Dashboard en Vivo (DashboardActivity)

Anillos de Actividad Diaria

Visualización de calorías quemadas (300 kcal), tiempo de ejercicio (30 min), horas de pie (5 hrs) y meta de pasos (10,000).

Sensor Cardíaco en Segundo Plano

Alimentado por ServicioMonitoreo: genera lecturas periódicas de BPM y dispara alertas automáticas en caso de taquicardia (> 100 BPM).

Compartir Reporte

Botón que usa ACTION_SEND para enviar un reporte resumido de la sesión por WhatsApp, correo o cualquier aplicación compatible.

Características Técnicas

Bajo el Capó

Multithreading y Servicios

ServicioMonitoreo ejecuta un Thread propio que genera BPM aleatorio cada 3 s. Si supera 100, simula taquicardia sin bloquear el UI Thread.

Comunicación Service → Activity

Broadcasts restringidos a la propia app (setPackage). Recibe con BroadcastReceiver + RECEIVER_NOT_EXPORTED. Un único diálogo de alerta se actualiza en vez de apilar uno nuevo cada 3 s.

Ciclo de vida seguro

Hilo detenido con interrupt() + bandera volatile al cerrar el Dashboard. Receptor registrado en onResume() y desregistrado en onPause().

Compatibilidad Android 15/16

targetSdk 36: pantallas de borde a borde. InsetsUtil aplica el espacio de las barras del sistema para que nada quede tapado.
