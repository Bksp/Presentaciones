## Ventajas de Usar Markdown

- **Estructura Simple:** Escribe contenido en texto plano.
- **Rápido de editar:** Ideal para documentación y notas rápidas.
- **Formato estándar:** Compatible con tablas, listas y bloques de código.

```python
def saludar(nombre):
    return f"¡Hola {nombre}, bienvenido a Reveal.js!"

print(saludar("Desarrollador"))
```
